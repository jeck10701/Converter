## 📥 How to Download & Install

1. Go to the [**Releases Page**](https://github.com/jeck10701/Converter/releases) on the right side of this repository.
2. Locate the latest release (e.g., `v1.0.0`) under the **Assets** section.
3. Download the file according to your OS:

| Platform | Recommended File | Installation Guide |
|----------|------------------|-------------------|
| 🪟 **Windows** | `ConvertX Setup 1.0.0.exe` | Download & double-click to run setup. A shortcut will appear on Desktop. |
| 🪟 **Windows (Portable)** | `ConvertX 1.0.0.exe` | Run directly without installation. |
| 🍎 **macOS** | `ConvertX-1.0.0.dmg` | Open file & drag ConvertX to Applications. |
| 🐧 **Linux** | `ConvertX-1.0.0.AppImage` | Make executable, then run. |

## ✨ Features

- **100% Private** — All conversions happen locally on your device. Files are never uploaded.
- **255+ Formats** — Images, Documents, Video, Audio, E-books, Archives, Vector, 3D Models.
- **Batch Convert** — Drop 1 or 100 files at once, converted in parallel.
- **Donut Picker** — Drag a file, a donut ring of compatible formats appears. Hover and drop.
- **Instant Download** — Converted files are ready in seconds.
- **Free & Open Source** — No ads, no watermarks, MIT Licensed.

## 🚀 Running from Source

If you want to run or build the app from source code:

### Prerequisites
- [Node.js](https://nodejs.org/) v18 or higher
- npm v8 or higher

```bash
# 1. Clone the repository
git clone [https://github.com/jeck10701/Converter.git](https://github.com/jeck10701/Converter.git)
cd Converter

# 2. Install dependencies
npm install

# 3. Run the app in development mode
npm start
