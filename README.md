## ✨ Features

- **100% Private** — All conversions happen on your device. Files are never uploaded.
- **255+ Formats** — Images, Documents, Video, Audio, E-books, Archives, Vector, 3D Models
- **Batch Convert** — Drop 1 or 100 files at once, converted in parallel
- **Donut Picker** — Drag a file, a donut of compatible formats appears. Hover and drop.
- **Instant Download** — Converted files are ready in seconds
- **Free & Open Source** — No ads, no watermarks, MIT Licensed

## 🚀 Running from Source

If you want to run the app from source code:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/convertx.git
cd convertx

# 2. Install dependencies
npm install

# 3. Run the app
npm start
```

### Build your own installer

```bash
# Windows (.exe)
npm run build:win

# macOS (.dmg)
npm run build:mac

# Linux (.AppImage)
npm run build:linux
```

Build output will be in the `dist/` folder.
